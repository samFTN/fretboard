Comment utiliser le Fretboard

Mode Gammes
Sélectionnez une gamme et une tonalité pour visualiser toutes les notes sur le manche.

Mode Arpèges
Affichez les notes d'un arpège dans la tonalité de votre choix.

Mode Notes personnalisées
Cochez les notes que vous voulez afficher. Double-cliquez directement sur le manche pour épingler une note à une position précise.

Notation
Basculez entre la notation universelle (C, D, E…), française (Do, Ré, Mi…) ou par degrés (1, 2, 3…).
